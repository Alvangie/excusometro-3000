# Excusómetro 3000

**Pabellón:** Pabellón 2 – Vida de Estudiante  
**Ingrediente improbable:** Número absurdamente preciso  

## El problema
Todo estudiante sufrió alguna vez ese microinfarto al mirar el reloj y darse cuenta de que llega tarde a clase, no mandó un trabajo práctico a horario o dejó en visto al grupo. En ese momento de pánico, el cerebro se bloquea y termina recurriendo a las mismas excusas quemadas de siempre que ya nadie cree.

## La solución
Excusómetro 3000 es un generador táctico de excusas bajo presión. A partir de tres datos rápidos (destinatario, gravedad de la falta y nivel de desesperación), el sistema ensambla un mensaje natural listo para copiar y pegar, calcula un número absurdamente preciso de credibilidad y genera una evidencia técnica simulada en tiempo real (pantalla de error con fecha y hora actual) para respaldar la coartada.

## Cómo probarlo
1. Clonar este repositorio o descargar el proyecto.
2. Abrir `index.html` en cualquier navegador web (Chrome, Brave, Edge, Firefox).
3. Elegir a quién va dirigido el mensaje, ajustar el nivel de gravedad y desesperación, y presionar **"Generar Coartada + Evidencia"**.
4. Copiar el texto generado o descargar la captura de prueba simulada.

## Herramientas de IA utilizadas
* **Gemini:** Utilizado para estructurar la ficha del invento, redacción del `README.md`, diseño de la interfaz web con Tailwind CSS y programación de la lógica de generación de excusas, métricas y evidencia visual en JavaScript.
